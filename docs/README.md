## A note on formatting

These documents were authored as fixed-width text (aligned tables, box-drawn
section rules). The Markdown wrappers preserve that layout inside a code fence
rather than reflowing it, so column alignment survives GitHub rendering.

## Confidence tiers

Claims throughout carry an explicit tier. Do not flatten them when quoting:

- **Measured / published** — traceable to a peer-reviewed result
- **Derived** — computed here from primary sequence data (reproducible from `data/`)
- **Inferred** — our reading of the evidence, not itself a published result
- **Unverified** — asserted somewhere upstream but not yet traced to a primary source
