# Construct Design

Design specifications, primer sets, and validation plans.

Nothing here is committed for synthesis. Constructs are added as design
documents first, reviewed, and only then ordered — see `CONTRIBUTING.md` for
the review path and `Stage_0_In_Silico_Planning.md` for what the in-silico
stage has to produce before a construct proceeds.

## Biosafety

CTV is a regulated plant pathogen. Every construct in this directory requires
institutional biosafety approval before any material is ordered or any plant is
inoculated. Design documents may be drafted and reviewed freely; approval is a
precondition for wet work, not a formality that follows it.
