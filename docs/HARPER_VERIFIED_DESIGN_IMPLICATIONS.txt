Harper Figure 2 (RT-qPCR): "No significant difference (Tukey HSD P > 0.05)

⇒ **TITER IS RULED OUT** — viral RNA accumulation identical across hybrids
⇒ **MECHANISM IS LIKELY FOREGUT BINDING** — direct vector-protein interaction

IMPLICATION FOR CONSTRUCT DESIGN
─────────────────────────────────

**PHASE 1 (NECESSITY TEST):**
  Construct: FS577 + T36's p65 (2 aa) + T36's p61 (9 aa)
  Background: FS577 (transmissible)
  Hypothesis: If these 11 changes are sufficient to disable transmission,
              transmission should drop from 24% toward 0-5% range
  Expected outcome: 0-5% (test of sufficiency)
  n per construct: 250-300 aphids (see Stage_0 power section)

**RATIONALE:**
  ✓ Tests the larger effect (p61+p65 together, not separately)
  ✓ Starts with transmissible background (lower risk of assembly failure)
  ✓ Avoids false negatives from testing individually (Harper showed they don't work alone)
  ✓ Directly mirrors Grok's proposal (FS577 backbone + T36 residues)

**PHASE 2 (IF PHASE 1 SUCCEEDS):**
  Option A: Individual genes (p61 alone; p65 alone) to rank importance
  Option B: Reciprocal (T36 + FS577 p65/p61) to confirm causality
  Option C: Subset testing (identify minimal residues, if desired)

**WHAT THIS CONTRADICTS:**
  ✗ DeepSeek's "minimal subset" idea (D324G, E382D, D458G charged residues)
    → If Harper's data is right, you need ALL 11 residues in Phase 1
  ✗ Individual-gene testing as Phase 1
    → Neither gene alone works; synergy is required
  ✗ K174R in p33 as Phase 1
    → p33 is a separate mechanism (literature: 16-23 pp effect)
    → If p33 is titer/replication, but p65/p61 is binding, test binding first
